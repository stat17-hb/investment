# 📈 표준편차 매매법 백테스트 대시보드

표준편차 매매법의 효과를 다양한 종목에서 테스트할 수 있는 인터랙티브 대시보드입니다.

## 🎯 전략 개요

**표준편차 매매법**은 통계적 접근을 통한 분할 매수 전략입니다:

### 핵심 로직

**전일까지의 일일 표준편차**와 **당일 수익률**을 비교하여 매수 시점을 결정합니다.

- **1년(252거래일) 기준 표준편차 계산**: 과거 1년간 일일 수익률의 변동성 측정
- **1σ 매수**: 당일 수익률이 전일까지의 일일 표준편차 이상 하락 시 매수
  - 예: 전일까지 일일 표준편차 3.0%, 당일 -3.0% 이상 하락 시
  - 통계적으로 연간 약 20회 발생
- **2σ 매수**: 당일 수익률이 전일까지의 일일 표준편차의 2배 이상 하락 시 매수
  - 예: 전일까지 일일 표준편차 3.0%, 당일 -6.0% 이상 하락 시
  - 통계적으로 연간 약 10회 발생
- **분할 매수로 평균 단가 낮추기**: 여러 번에 걸쳐 매수
- **목표 수익률 또는 이동평균선 회귀 시 매도**

### 전략의 핵심 원리

```
실제 구현 로직:

1. T-1일까지의 일일 표준편차 계산 (252일 롤링)
   Daily_Std_Dev[T-1] = std(Returns[T-252:T-1])

2. T일의 수익률 계산
   Returns[T] = (Close[T] - Close[T-1]) / Close[T-1]

3. 매수 조건 판단 (Lookahead Bias 방지)
   - 1σ 매수: Returns[T] <= -Daily_Std_Dev[T-1]
   - 2σ 매수: Returns[T] <= -2 × Daily_Std_Dev[T-1]

💡 T일의 결정은 오직 T-1일까지의 데이터로만 이루어짐
   → 실제 거래 가능한 전략
```

### 통계적 근거

- **평균 회귀(Mean Reversion)**: 과도하게 하락한 가격은 평균으로 회귀하려는 성질
- **정규분포 가정**: 일일 수익률이 정규분포를 따른다는 가정 하에 극단적 하락을 매수 기회로 활용
- **Lookahead Bias 방지**: 미래 데이터를 사용하지 않아 백테스트 결과의 신뢰성 확보

## 📊 기능

### 1. 현재 분석
- 실시간 매수 가격 계산 (1σ, 2σ)
- 현재 표준편차 및 RSI 지표
- 최근 매수 시그널 히스토리
- 연간 매수 기회 통계

### 2. 백테스트 결과
- **수익성 지표**: 총 수익률, CAGR (연평균 복리 수익률)
- **위험 조정 성과**: Sharpe Ratio, Sortino Ratio, Calmar Ratio
- **위험 지표**: 최대 낙폭(MDD), 변동성
- **거래 통계**: 거래 횟수, 승률, 손익비, 평균 보유 기간
- **Buy & Hold 비교**: 동일 조건에서 매수 후 보유 전략과 비교

### 3. 차트 분석
- 가격 + 표준편차 밴드 시각화 (TradingView 스타일)
- 매수 시그널 표시 (1σ, 2σ 구분)
- RSI 지표 (과매수/과매도)
- 이동평균선 (MA20, MA60)
- 수익률 분포 분석 (히스토그램 + 정규분포 비교)
- **Tail Risk 분석**: VaR, CVaR, 극단 이벤트 시각화

### 4. 거래 내역
- 모든 매수/매도 거래 상세 내역
- 거래별 수익률 및 보유 기간
- 매도 사유 (목표 수익, 손절, 트레일링 스톱 등)
- 필터링 및 정렬 기능
- CSV 다운로드

### 5. 위험 관리 기능
- **손절선 (Stop Loss)**: 매수가 대비 일정 비율 이상 손실 시 자동 매도
- **트레일링 스톱 (Trailing Stop)**: 보유 중 최고가 대비 일정 비율 하락 시 매도
- **손절 후 쿨다운**: 손절 후 일정 기간 매수 금지로 연속 손실 방지
- **목표 수익률**: 계좌 전체 수익률 기준 자동 청산

### 6. 포지션 사이징
- **고정 금액**: 매번 동일한 금액으로 매수
- **동적 비율**: 보유 현금의 일정 비율로 매수 (복리 효과)

## 🎮 사용 방법

### 기본 사용법

1. **종목 티커 입력**: 예) `SOXL`, `TQQQ`, `QLD`, `NVDA`
2. **설정 조정**:
   - **데이터 기간**: 1년 ~ max (종목별로 가능한 전체 기간)
   - **표준편차 계산 기간**: 기본 252일 (1년)
   - **초기 자본금**: 백테스트 시작 자본
   - **포지션 사이징**: 고정 금액 또는 현금 비율
   - **매수 기준**: 1σ 또는 2σ
   - **목표 수익률**: 계좌 전체 수익률 목표
   - **위험 관리**: 손절선, 트레일링 스톱, 쿨다운 설정
3. **분석 시작** 버튼 클릭
4. **결과 확인** (4개 탭: 현재 분석, 백테스트 결과, 차트, 거래 내역)

### 백테스트 설정 팁

1. **보수적 접근**:
   - 2σ 매수 (더 큰 하락에만 매수)
   - 높은 목표 수익률 (50%+)
   - 손절선 활성화 (10-15%)

2. **공격적 접근**:
   - 1σ 매수 (더 자주 매수)
   - 낮은 목표 수익률 (20-30%)
   - 트레일링 스톱 활용

3. **분산 투자**:
   - 고정 금액: 총 자본의 10% 이하로 설정
   - 동적 비율: 현금의 20% 수준

4. **레버리지 ETF 주의사항**:
   - 변동성이 크므로 트레일링 스톱 비율을 20-30%로 넉넉히 설정
   - 쿨다운 기간 설정으로 연속 손실 방지

## 🔧 주요 클래스 및 함수

### `DataFetcher` (data_fetcher.py)
Yahoo Finance에서 주가 데이터를 가져옵니다.

```python
fetcher = DataFetcher("SOXL")
data = fetcher.get_historical_data(period="2y", extra_days=252)
info = fetcher.get_info()
```

### `StandardDeviationStrategy` (strategy.py)
표준편차 매매 전략을 적용하고 시그널을 생성합니다.

**핵심 기능:**
- 일일 수익률 및 표준편차 계산 (252일 롤링)
- Lookahead Bias 방지 (T-1일 데이터로 T일 결정)
- 1σ, 2σ 매수 시그널 생성

```python
strategy = StandardDeviationStrategy(data, lookback_period=252)
current_stats = strategy.get_current_stats()
signals = strategy.get_buy_signals(sigma_level=1)
```

### `Backtester` (backtest.py)
백테스트를 실행하고 성과를 계산합니다.

**주요 기능:**
- 포지션 사이징 (고정 금액 / 동적 비율)
- 위험 관리 (손절, 트레일링 스톱, 쿨다운)
- Buy & Hold 비교 (DCA 지원)
- 성과 지표 계산 (Sharpe, Sortino, Calmar, MDD 등)
- Tail Risk 분석 (VaR, CVaR)

```python
backtester = Backtester(
    data=strategy.data,
    initial_capital=10000,
    position_size=1000,
    sigma_level=1,
    use_take_profit=True,
    take_profit_pct=50,
    use_trailing_stop=True,
    trailing_stop_pct=30,
    cooldown_months=0
)
results = backtester.run()
```

## ⚠️ 주의사항

### 투자 리스크
1. **과거 성과가 미래 수익을 보장하지 않습니다**
2. **레버리지 ETF는 변동성이 크고 시간 가치 감소(decay) 위험이 있습니다**
3. **분할 매수를 위한 충분한 현금 보유가 중요합니다**
4. **백테스트는 수수료, 슬리피지, 세금을 고려하지 않습니다**

### 전략의 한계
1. **정규분포 가정**: 실제 시장은 정규분포를 따르지 않으며 극단적 이벤트(Fat Tail)가 더 자주 발생합니다
2. **평균 회귀 가정**: 모든 하락이 회복되는 것은 아닙니다 (개별 종목 상장폐지 위험)
3. **시장 환경 변화**: 과거에 효과적이었던 전략이 미래에도 유효하리라는 보장 없음
4. **변동성 변화**: 시장 상황에 따라 표준편차가 급변할 수 있음

### 권장사항
1. **ETF 우선**: 개별 종목보다 ETF가 안전합니다
2. **소액으로 시작**: 실전 투자 시 소액으로 전략을 검증해보세요
3. **위험 관리 필수**: 손절선과 트레일링 스톱을 반드시 설정하세요
4. **분산 투자**: 한 종목에 올인하지 마세요
