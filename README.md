# 📈 표준편차 매매법 백테스트 대시보드

표준편차 매매법의 효과를 다양한 종목에서 테스트할 수 있는 인터랙티브 대시보드입니다.

## 🎯 전략 개요

**표준편차 매매법**은 통계적 접근을 통한 분할 매수 전략입니다:

- **1년(252거래일) 기준 표준편차 계산**: 일일 변동성의 통계적 범위 파악
- **1σ 하락 시 매수**: 68% 확률 범위 이탈 시 (연간 약 20회 기회)
- **2σ 하락 시 추가 매수**: 95% 확률 범위 이탈 시 (연간 약 10회 기회)
- **분할 매수로 평균 단가 낮추기**: 여러 번에 걸쳐 매수
- **목표 수익률 또는 이동평균선 회귀 시 매도**

### 전략의 핵심 원리

```
정규분포 개념 적용:
- 중심: 현재 가격
- 1σ: 68% 확률 범위 (±1 표준편차)
- 2σ: 95% 확률 범위 (±2 표준편차)

가격이 표준편차 이하로 하락 = 통계적으로 저평가
→ 매수 기회!
```

## 🚀 설치 방법

### 1. 저장소 클론 (또는 파일 다운로드)

```bash
cd investment
```

### 2. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

### 3. 대시보드 실행

```bash

```

브라우저가 자동으로 열리며 `http://localhost:8501`에서 대시보드를 확인할 수 있습니다.

## 📊 기능

### 1. 현재 분석
- 실시간 매수 가격 계산 (1σ, 2σ)
- 현재 표준편차 및 RSI 지표
- 최근 매수 시그널 히스토리
- 연간 매수 기회 통계

### 2. 백테스트 결과
- 총 수익률 및 Buy & Hold 비교
- 승률, 평균 수익률, 최대 낙폭(MDD)
- 포트폴리오 가치 변화 그래프
- 거래 통계 (거래 횟수, 평균 보유 기간 등)

### 3. 차트 분석
- 가격 + 표준편차 밴드 시각화
- 매수 시그널 표시
- RSI 지표
- 이동평균선 (MA20, MA60)

### 4. 거래 내역
- 모든 매수/매도 거래 상세 내역
- 거래별 수익률 및 보유 기간
- 필터링 및 정렬 기능
- CSV 다운로드

## 🎮 사용 방법

### 기본 사용법

1. **종목 티커 입력**: 예) `SOXL`, `TQQQ`, `SPY`, `NVDA`
2. **설정 조정**:
   - 데이터 기간 (1~5년)
   - 표준편차 계산 기간 (기본 252일 = 1년)
   - 초기 자본금 및 1회 매수 금액
   - 매수 기준 (1σ 또는 2σ)
   - 목표 수익률
3. **분석 시작** 버튼 클릭
4. **결과 확인**

### 추천 종목

**레버리지 ETF** (영상에서 언급된 종목):
- `SOXL`: 반도체 3배 레버리지 (영상 주요 종목)
- `TQQQ`: 나스닥100 3배 레버리지
- `UPRO`: S&P500 3배 레버리지
- `TMF`: 미국 20년 국채 3배 레버리지

**일반 ETF**:
- `SPY`: S&P500
- `QQQ`: 나스닥100
- `SMH`: 반도체

**개별 종목**:
- `NVDA`: 엔비디아
- `TSLA`: 테슬라
- `AAPL`: 애플

### 백테스트 설정 팁

1. **보수적 접근**: 2σ 매수 + 높은 목표 수익률 (20%+)
2. **공격적 접근**: 1σ 매수 + 낮은 목표 수익률 (10%)
3. **분산 투자**: 1회 매수 금액을 총 자본의 10% 이하로 설정

## 🔧 주요 클래스 및 함수

### `DataFetcher` (data_fetcher.py)
Yahoo Finance에서 주가 데이터를 가져옵니다.

```python
fetcher = DataFetcher("SOXL")
data = fetcher.get_historical_data(period="2y")
```

### `StandardDeviationStrategy` (strategy.py)
표준편차 매매 전략을 적용하고 시그널을 생성합니다.

```python
strategy = StandardDeviationStrategy(data, lookback_period=252)
current_stats = strategy.get_current_stats()
```

### `Backtester` (backtest.py)
백테스트를 실행하고 성과를 계산합니다.

```python
backtester = Backtester(
    data=strategy.data,
    initial_capital=10000,
    position_size=1000,
    sigma_level=1
)
results = backtester.run()
```

## ⚠️ 주의사항

1. **과거 성과가 미래 수익을 보장하지 않습니다**
2. **레버리지 ETF는 변동성이 크므로 신중하게 투자하세요**
3. **분할 매수를 위한 충분한 현금 보유가 중요합니다**
4. **개별 종목보다 ETF가 안전합니다** (영상 내용 참고)
5. **백테스트는 수수료, 슬리피지를 고려하지 않습니다**
